# Nuvaira

> Nuvaira, Inc. is a privately held medical device company in Minneapolis, Minnesota, founded in
> 2008. Its dNerva Lung Denervation System is a catheter-based radiofrequency device used in a
> bronchoscopic procedure called Targeted Lung Denervation (TLD) to treat overactive airway nerves
> in people with COPD. The FDA has designated it a Breakthrough Device.

## API surface

Nuvaira publishes **no API**. As of 2026-08-26 there is no developer portal, no public API
reference, no OpenAPI/AsyncAPI/GraphQL/gRPC/WSDL contract, no SDK in any public package registry,
no MCP server, and no A2A agent card. The product is a regulated physical therapeutic device sold
to hospitals and interventional pulmonologists, not software. Every `/.well-known/` discovery path
on nuvaira.com returns HTTP 404 (see `well-known/nuvaira-well-known.yml`).

The only machine-readable surface reachable on nuvaira.com is the stock WordPress core REST API at
`/wp-json/`, which describes the marketing website's CMS — it is WordPress's contract, not a
Nuvaira product API, and it is deliberately not cataloged as one.
